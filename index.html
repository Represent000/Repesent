我们如何选文与定级（选文标准）

选文方法参照 JOSPT 2025《肩袖肌腱病临床实践指南》（doi:10.2519/jospt.2025.13182）的循证流程，向读者透明公开。

① 来源筛选通过 PubMed / Google Scholar / 期刊官网 / Cochrane Library / NICE 等多来源交叉检索，优先临床实践指南、系统评价/Meta 分析；期刊优先高影响因子（BMJ、Lancet、JOSPT、Cochrane、Br J Sports Med 等）。每篇文献均附 DOI 并经 doi.org 校验，点击「文章主页」直达出版社原文页，保证真实可追溯。
② 双人独立质评系统评价用 AMSTAR II，RCT 用 EPHPP/偏倚风险（ROB），分歧由第三人裁决；每篇文献先评质量再定证据等级。
③ 证据分级CEBM 五级（Level I 系统评价/高质量 RCT → Level V 专家意见），并按 GRADE 置信度（高/中/低/极低）复核；Meta 分析因偏倚风险、异质性等可降级。
④ 推荐分级Guyatt/MacDermid 改良 A–F：A 强证据 · B 中等 · C 弱 · D 冲突 · E 理论 · F 专家意见（本站以 A/B/C/D 对应展示）。
⑤ 完整证据合成每条推荐附效应量（MD/SMD + 95%CI）、纳入 RCT 数与总样本量，读者可自行核对原文，不依赖单一结论。

证据分级说明（基于 GRADE 简化）

每条干预同时给出「证据等级」与「推荐强度」，反映其可信度与临床建议力度。

等级含义主要来源
A 高结果可靠，进一步研究难改变结论系统评价 / 高质量 RCT / 权威指南
B 中有一定把握，未来研究可能改变结论多个 RCT / 观察性研究汇总
C 低把握有限，需谨慎解读单中心 RCT / 队列 / 病例对照
D 极低证据薄弱，多靠专家判断或临床经验病例系列 / 专家共识 / 机制推断
强推荐收益显著大于风险，多数情况下应执行
弱推荐收益略大于风险，需结合患者情况权衡
建议 / 可选可作为辅助或个体化选择
不推荐 / 反对证据表明风险大于收益或无效
无充分证据尚无足够证据判断利弊
